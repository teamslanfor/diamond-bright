# Diamond Bright Cleaning Services

Five-page React and Vite website for Diamond Bright Cleaning Services in Belfast. Routes: Home, Services, About, Videos, and Contact.

## Preview locally

```bash
npm install
npm run dev
```

The app runs at the local Vite URL. Each page has its own route and page metadata.

## Build

```bash
npm run build
```

The static site is generated in `dist/`.

## Chat assistant and videos

The quick-answer assistant is a small client-side FAQ for services, listed hours, and quote enquiries. It is not connected to a live agent or an AI service. The videos page embeds illustrative Pexels stock clips and links to the business's Facebook page for business-shared videos.

## Contact form

The enquiry form validates the required fields and opens the visitor’s email application with a prefilled message to `info@diamondbright.co.uk`. It does not submit data to a server. To collect enquiries directly on the website, connect a form service or backend endpoint and update the form handler.
