# Diamond Bright Cleaning Services — Project Index

## Start here
- `index.html` — Vite entry page and global metadata.
- `src/main.jsx` — React app and user interface for Home, Services, About, Videos, Contact, navigation, quote form, and quick-answer assistant.
- `src/styles.css` and `src/overrides.css` — responsive layout, typography, colors, and UI styling.

## Routes
- `/` — Home (`index.html`)
- `/services/` — `services/index.html`
- `/about/` — `about/index.html`
- `/videos/` — `videos/index.html`
- `/contact/` — `contact/index.html`

## Project files
- `package.json` and `package-lock.json` — dependencies and npm commands.
- `vite.config.js` — Vite and React configuration.
- `public/favicon.svg` — site icon.
- `.openai/hosting.json` — hosting project configuration.
- `dist/` — production-ready static build output and bundled assets.
- `README.md` — setup, build, form behavior and content notes.

## Run locally
Install Node.js, then run `npm install` followed by `npm run dev`. Use `npm run build` to regenerate `dist/`.

The contact form opens the visitor’s email application with a prefilled message. It does not submit data to a server.
